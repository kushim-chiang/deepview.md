# Welcome to DeepView MD / 歡迎使用深閱MD

**DeepView MD** is your intelligent Markdown reader and editor, designed for a comfortable, focus-driven reading experience enhanced by AI.

**DeepView MD** 是您的智慧 Markdown 閱讀器與編輯器，專為舒適、專注的閱讀體驗而設計，並結合 AI 增強功能。

---

## 🚀 Key Features / 主要功能

### 1. AI-Powered Assistance / AI 智慧輔助

- **Contextual Help**: Select text or place your cursor anywhere, then tap the **"AI Assistant"** button to summarize, translate, or explain code.
- **Prompt Templates**: Use built-in templates like "Summarize", "Translate to Traditional Chinese", or create your own custom prompts.
- **上下文輔助**：選取文字或將游標置於任意處，點擊 **「AI 助理」** 按鈕，即可進行總結、翻譯或程式碼解釋。
- **提示詞範本**：內建「精簡總結」、「翻譯成正體中文」等實用範本，您也可以建立自己的專屬提示詞。

### 2. Comfortable Reading / 舒適閱讀

- **Gustatory Design System**: A warm, high-contrast theme ("Cinnamon & Chocolate") designed to reduce eye strain.
- **Focus Mode**: Distraction-free reading environment.
- **味覺設計系統**：採用溫暖、高對比的「肉桂與巧克力」主題，大幅降低長時間閱讀的視覺疲勞。
- **專注模式**：提供無干擾的純淨閱讀環境。

### 3. Efficient Editing / 高效編輯

- **Quick Actions**: Insert links, format text, and navigate documents with ease.
- **Slash Commands**: Type `/` to access AI features quickly (coming soon).
- **快速操作**：輕鬆插入連結、格式化文字與導覽文件。
- **斜線指令**：輸入 `/` 即可快速呼叫 AI 功能（即將推出）。

### 4. Line Tools & Navigation / 行號工具與導覽

- **One-tap line copy**: Tap a line number to copy that line instantly. When you drag across line numbers, multiple lines are copied at once—perfect for sharing with AI for translation, explanation, or deep analysis.
- **Jump by line**: Move through the document by jumping to a specific line, or go straight to the first or last line for quick review.
- **Context menu formatting**: Select text and use the context menu to bold, add links, or mark code in one tap.
- **Symbol toolbar**: A handy keyboard row for common Markdown symbols like `#`, `[]`, `()`, `` ` ``, and `>`, so you can type faster with fewer keystrokes.
- **單行快速複製**：輕點行號即可複製該行；手指在行號間滑動時可一次複製多行，方便丟給 AI 做翻譯、解釋或深入研究。
- **行號跳轉**：可指定行號跳躍，也能一鍵直達第一行或最後一行，檢閱超省時。
- **選取即格式化**：選取文字後，在 context menu 直接套用粗體、連結或 code 標示，少敲字、多效率。
- **符號鍵盤列**：額外鍵盤列附常用 Markdown 符號（如 `#`、`[]`、`()`、`` ` ``、`>`），不用切換鍵盤就能快速輸入。

### 5. Personalized Comfort / 個人化舒適

- **Adjustable font size**: Enlarge or shrink text to your preference for a more eye-friendly reading session.
- **Auto-resume reading**: Your last reading position is remembered, so long documents reopen right where you left off—perfect for multi-session reviews.
- **可調整字級**：依喜好放大或縮小文字，長時間閱讀也更舒適。
- **自動記錄進度**：重新打開檔案時直接回到上次閱讀位置，長文分段看也不會迷路。

## 💡 How to Use / 使用教學

1.  **Create a Note**: Tap the **"Create New"** button on the home screen.
2.  **Edit**: Tap anywhere to start writing Markdown.
3.  **AI Assist**: Tap the ✨ icon in the toolbar to summon the AI Assistant.
4.  **Manage Files**: Long-press a file card to rename or delete it.

1.  **建立筆記**：點擊首頁的 **「建立新文件」** 按鈕。
2.  **編輯內容**：點擊任意處即可開始撰寫 Markdown。
3.  **AI 助理**：點擊工具列上的 ✨ 圖示，呼叫 AI 幫手。
4.  **管理檔案**：長按檔案卡片可進行更名或刪除。
